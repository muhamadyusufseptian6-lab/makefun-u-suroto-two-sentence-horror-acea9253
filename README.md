## The story

> A parcel waited on my doorstep at 6:04 this morning, addressed in my own handwriting, though I ordered nothing. Inside was a photograph of me opening it, taken from inside my flat.

Two sentences, one quiet knock of dread: the first sets a small wrong thing — a parcel I never ordered, in handwriting I recognise as my own. The second turns it — the photograph was taken from inside my flat, which means whoever sent it was already in.

## How it works

`main.ts` (Node 22, stdlib-only, deterministic) writes the story to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

The output is UTF-8 text of 1–400 characters, exactly two sentences, no more, no less.
